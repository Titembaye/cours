# Classification de textes

## Objectifs

- Vectoriser des textes avec BoW et TF-IDF
- Entraîner un classifieur Naïf de Bayes et un SVM linéaire
- Évaluer : précision, rappel, F1, matrice de confusion
- Comparer les configurations représentation × classifieur

## Dataset

**Banking77** — 77 catégories d'intentions bancaires en anglais.
